# Archived Rust/Bevy implementation

This directory preserves the former Rust/Bevy source tree and Rust tests as migration reference. It is not the active implementation and is not built by the root CMake project.

Use this code and the historical `Docs/` files to recover intended behavior during the C++20/Flecs port. Migrate behavior deliberately; do not treat these files as current architecture documentation. The old workflows and Rust dependency files are not active build configuration.
